# puffer-core 287: Workflow action target runtime ids

Workflow command helper summaries now read the internal
`ActionSpec::RunWorkflow.workflow_id` field when displaying workflow action
targets.

The user-facing output is unchanged: summaries still render
`workflow=<id>`. The binding JSON compatibility field remains `slug`; this
change only tracks the typed Rust field rename used by
`puffer-subscriptions`.
