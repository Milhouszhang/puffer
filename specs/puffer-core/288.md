# ConnectorActionDraft connection liveness

- `ConnectorActionDraft` now requires the resolved `connection_slug` to exist in the subscription manager's connection store before it writes an outbound draft.
- The connection must belong to the requested `connector_slug` and be in `authenticated` or `active` state. Missing, mismatched, disabled, degraded, created, or authenticating connections fail with an actionable `/connect <connector> <connection>` repair hint.
- This prevents a disconnected Telegram account from producing a `draft_ready` send card after the desktop disconnect flow removes the `telegram-user` connection.
- Existing human approval and execution semantics are unchanged: approved drafts still flow through `connector_action_execute` and the installed connector action executor.
