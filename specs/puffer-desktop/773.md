# Automation Home Library Tabs

## Summary

The desktop Automation home now removes the extra lower `Automations` title and
subtitle. The library below the composer uses a Langdock-style toolbar with
local tabs for user automations and templates, plus a `New automation` action
that opens the existing full-page creation screen.

## Behavior

- The prompt-first composer remains unchanged.
- The lower library starts on the `Your automations` tab.
- `Template Library` is hidden until the template tab is selected.
- `New automation` sits in the same toolbar as the tabs and opens the
  full-page create screen.
- Template cards still open the create screen with matching starter content.
- Returning from the create screen restores the home with the library toolbar.

## Architecture

`Automation.svelte` adds local `activeAutomationLibraryTab` state. The two tab
panels render mutually exclusively, so inactive cards are not duplicated in the
accessibility tree. The new button reuses the existing `openNewAutomation`
create-page path.

## Compatibility

No backend, storage, daemon RPC, or execution behavior is added. This is a
desktop UI-only change and keeps the existing create page contract intact.

## Testing

`tests/automation-ui.spec.ts` verifies removal of the old lower heading and
subtitle, tab switching between user automations and templates, the new create
button, template handoff, back navigation, and the absence of canvas/detail
surfaces.
