# Automation Create Save And Cancel

## Summary

The Automation create page now uses `Cancel` and `Save` actions instead of a
single `Create` button. Blank creation, prompt-based creation, and template
creation are separate UI paths.

## Behavior

- `New automation` opens a blank create page named `Untitled automation`.
- Sending from the home composer opens a draft create page, carries the
  composer text into `Instructions`, and pre-fills matching name, trigger, and
  app rows when the prompt describes a known automation pattern.
- Template cards open the create page with the template name, instructions, and
  trigger.
- `Cancel` returns to the Automation home without adding a card.
- `Save` adds a local user automation card for the current UI session and
  returns to the `Your automations` tab.
- Trigger menu items now set the visible trigger row and close the menu.

## Architecture

`Automation.svelte` keeps `automationTrigger`, `savedAutomations`, and a local
sequence counter in component state. Saved cards are prepended to the static
user automation list with a local-only `Saved` status. No daemon API, storage,
or execution wiring is introduced.

## Testing

`tests/automation-ui.spec.ts` verifies the absence of the old `Create` action,
the presence of `Cancel` and `Save`, blank new creation, prompt handoff,
template trigger handoff, trigger selection, cancel behavior, and local save
behavior.
