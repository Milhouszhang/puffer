# Automation Library Empty State

## Summary

The Automation home now treats `Your automations` as a real user-owned list. It
starts empty instead of showing sample automation cards.

## Behavior

- `Your automations` shows an empty state when there are no saved automations.
- The empty state includes a short title, a short sentence, and a creation
  action.
- Sample cards such as `Review inbox` are not shown in the user-owned tab.
- `Template Library` still shows starter templates.
- Saving a new automation returns to `Your automations` and displays the saved
  card.

## Architecture

`baseUserAutomations` is now empty, so the home list is driven only by local
saved automation state. The empty state is rendered in `Automation.svelte` when
`userAutomations.length` is zero.

This remains UI-only and does not introduce persistence or daemon calls.

## Testing

`tests/automation-ui.spec.ts` verifies the default empty state, confirms sample
automation cards are absent, and still verifies that saving an automation
creates a visible card in `Your automations`.
