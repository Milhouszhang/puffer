# Automation Detail Preview

## Summary

Automation cards now open a detail preview page. The page keeps the same compact
Puffer styling as the creation view while giving users a place to review,
adjust, save, and test an existing automation.

## Behavior

- Clicking a saved automation opens a full-page detail view instead of the
  creation page.
- The top bar shows a breadcrumb, `Test Run`, `Save`, and an overflow action.
- The overflow action opens a compact menu with a `Delete` action.
- The title/status area lets users rename the automation and toggle `Active`.
- The `Settings` tab shows editable trigger, instruction, and tool controls.
- The trigger picker closes when users click outside the picker.
- The tool picker closes when users click outside the picker.
- The `Run History` tab shows local run records and an empty state before the
  first run.
- `Test Run` adds a local run record and switches to `Run History`.
- `Save` writes the edited local configuration back to the saved card.

## Architecture

This remains desktop UI state only. Saved cards now carry the local trigger,
instruction, selected tool, enabled, owner, and run-history data needed by the
detail preview. The existing trigger and tool picker controls are reused so
creation and detail editing share the same interaction model.

## Testing

`tests/automation-ui.spec.ts` verifies opening a saved automation, editing and
saving settings, switching tabs, and adding a `Test Run` history entry.
