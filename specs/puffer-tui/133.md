# puffer-tui 133: Workflow action popup runtime ids

Workflow action popup summaries now read the internal
`ActionSpec::RunWorkflow.workflow_id` field when displaying run-workflow
targets.

The popup text remains `workflow=<id>`, and serialized binding compatibility
continues to use the JSON `slug` field. This keeps the TUI display aligned with
the subscriptions runtime-id contract without changing the visible UI format.
